# 几何位置：DE441 与全量理论对照

[中文首页](../README.md) · [English README](../README.en.md) · [精度与适用范围](./accuracy.md)

## 方法与限制

本次对照日期为 2026-09-02；不修改或重新拟合任何生产系数。参考值为 JPL DE441，
比较的是同一时刻、同一中心、转换到 ICRF 方向约定后的几何位置向量。
不包含光行时、光行差、章动、观测者视差，也不测试速度或天象事件的求根误差。

- 每个区间独立取 2,048 个分层随机日期，另加两端点，共 **2,050 个日期**；
  所有模型在同一区间使用完全相同的日期。NumPy `default_rng` / PCG64，种子 `2026090201`。
- 年份定义为儒略年 `y = 2000 + (JD − 2451545) / 365.25`，不是逐个民用年元旦。
  抽样区间依次为 `1600..2200`、`-1000..3000`、`-6000..10000`，天文年 0 表示公元前 1 年。
- 输入使用相同数值 JD：本库按 TT 接收，DE441 按 TDB 求值，未在本测试中另作 TT–TDB 换算。
  这是模型对照，不是高精度时间尺度验收。
- 单点误差是 `||r_model − r_DE441||₂`；RMS 是这个三维距离误差的均方根，
  不是将三个分量再除以 √3。表内最大值是**样本最大值**，不是连续区间上界。
- 本库曾按 DE441 校准。VSOP87A 的原始拟合基准是 DE200；VSOP2013/TOP2013 是 INPOP10a；
  此处 ELP/MPP02 使用 DE405 拟合参数及其发布的长期角度修正，ELP2000-82B 使用 DE200/LE200 常数。
  未给全量理论额外拟合 DE441，也没有按这次结果调整系数。
- 宽年代列包含原始理论超出其设计／验证范围的外推，只用于展示差异增长；
  不能据此把本库整个 `-6000..10000` 区间声明为统一高精度，或把其他理论判为失效。
- 各模型体积、项数和计算成本不同。本次不比较速度，也不是同预算截断实验。
  “全量”指完整公开系数表，不意味着无限项的解析理论或零误差。

### 中心与坐标系

水星、金星、火星及外行星对照 DE441 的对应系统质心，减去太阳位置。
地月质心对照 `(0,3) − (0,10)`；物理地球中心为 `(0,3) + (3,399) − (0,10)`。
月球地心参考为 `(3,301) − (3,399)`，不与地月质心位置混用。

本库 `embPosition()` 由库内物理地球与月球模型重建质心，未借用 DE441 月球来消除自身误差。
VSOP2013 的第 3 体与 VSOP87A 的 `.emb` 直接给出地月质心。

各理论自己的“J2000 黄道”不自动等于相同坐标系。本次使用固定的源模型转换：

| 模型 | 转换到比较参考系 |
| --- | --- |
| 本库 | IAU 2006 J2000 倾角及 Vondrák 2011 带框架偏置的岁差矩阵之逆，与现有位置测试一致 |
| VSOP87A | 官方使用说明的 J2000 黄道 → FK5 矩阵，再乘 ERFA `fk5hip()` 的固定 J2000 FK5 → Hipparcos/ICRS 方向矩阵；不加入恒星自行旋转 |
| VSOP2013 / TOP2013 | 官方矩阵，`ε = 23°26′21.41136″`、`φ = −0.05188″`；使用其 AU 值 `149597870.691 km` |
| ELP2000-82B | 官方说明第 8 节的专用黄道 → FK5 矩阵，再接上述固定 FK5 → ICRS 方向转换 |
| ELP/MPP02 | 原始说明 Table 7 的 JPL405 参数行：`ε = 23°26′21.40960″`、`φ = −0.05028″`，与本次 DE405 拟合常数匹配 |

旧星历到现代 ICRF 的方向联系本身也有不确定性；这里使用发布的固定联系，
没有通过拟合测试样本消掉整体旋转。ELP/MPP02 的 JPL405 坐标系作为 ICRF 对齐的参考系使用，
未另拟合 DE405–DE441 的微小方向差。结果不应被解读为排除了所有框架差异的纯轨道理论误差。

## 行星全量对照

单位 km，单元格为 **RMS / 样本最大值**。本库为位置 `accurate` 档。
VSOP87 使用 **A 版**日心直角坐标完整表，不是 B/D 版，也不是某个应用的二次截断表。
TOP2013 使用公开的 **TOP2013LBR.dat** 全量直接坐标表，不与其轨道根数版混称为同一组数值。

求值器另行核对了官方控制文件：VSOP87A 的 90 组 XYZ、VSOP2013 的 88 组 XYZ，
以及 TOP2013LBR 的 44 组 L/B/R。最大分量差均小于 `6×10⁻¹¹`
（XYZ 为 AU，L/B 为 rad，R 为 AU），与控制文件保留的小数位一致。

## 复现

仓库内提供 [比较脚本](https://github.com/RedSC1/js-ephemeris-lite/blob/main/tools/benchmark-full-models.py)、
[ELP82B 调用驱动](https://github.com/RedSC1/js-ephemeris-lite/blob/main/tools/benchmark-elp82-driver.f90)
和[未取整指标及 SHA-256 清单](https://github.com/RedSC1/js-ephemeris-lite/blob/main/tools/benchmarks/model-accuracy.json)。
大型原始星历、系数文件和 Fortran 二进制不随 npm 包分发。

需要 Python 3.9+、NumPy、jplephem、pyerfa、Node.js，以及编译 ELP82B 的 gfortran。
外部数据路径由调用者提供；脚本要求输出目录为空，防止误用旧模型缓存。
`--elp-module` 接受 ES module，导出 `elpmpp02(daysSinceJ2000)`，返回全量 DE405 模式的
J2000 原生黄道 XYZ（km）；本次使用的完整模块及数据文件哈希保存在清单中。

```sh
gfortran -O2 -std=legacy -fno-automatic \
  tools/benchmark-elp82-driver.f90 "$ELP82_DIR/elp82b.f" \
  -o /tmp/benchmark-elp82

python3 tools/benchmark-full-models.py \
  --vsop87 "$VSOP87_DIR" \
  --vsop2013 "$VSOP2013_DIR" \
  --top2013 "$TOP2013_DIR" \
  --elp-module "$FULL_ELP_MODULE" \
  --elp82-data "$ELP82_DIR" \
  --elp82-binary /tmp/benchmark-elp82 \
  --de441 "$DE441_FILE" \
  --out /tmp/model-comparison-new
```

可用 `--samples 8` 做小样本接线检查，但 README 数字使用默认 `2048 + 2` 个日期。
生成器不执行模型训练、选项数或残差拟合；任何生产系数更新后都应重新运行，不能沿用本次数字。
