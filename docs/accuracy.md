# 精度与适用范围

[返回首页](../README.md) · [模型修正](./model-corrections.md)

## 日期范围

主要星历模型面向天文年 `-6000..10000`。需要前后年度数据的接口使用更窄的
查询范围，例如黄历日期入口为 `-5999..9999`。精度随天体、年代和计算设置变化。

## 几何位置与视位置

几何位置由截断 VSOP87B、ELP/MPP02 级数及 DE441 残差修正计算。
`corrections` 控制残差修正，默认开启；分层区间和算法见[模型修正](./model-corrections.md)。

`PLANET_CORRECTION_INFO` 提供行星几何日心模型的误差统计：

| 指标 | 含义 |
| --- | --- |
| RMS | 验证样本中的均方根残差 |
| p95 | 验证样本中 95% 的残差不超过的值 |
| 最大残差 | 验证样本中的最大值 |

经纬度残差单位为角秒，距离残差单位为 km。统计按天体和修正层分别提供，
适用于所列样本与模型设置；未采样时刻的误差可能更大。

视位置在几何星历上加入光行时、光行差、太阳光线偏折和参考面变换。
其误差同时取决于底层星历与这些计算步骤。地平位置还依赖时间、观测地点和大气参数。

## 天文事件与时间尺度

事件求解以 JD(TT) 进行，数值收敛容差控制求根过程。
事件时刻的实际精度还取决于星历、参考面和事件定义。
近远点附近的距离曲线较平，同样大小的位置误差可能产生较大的时刻差异。

TT 与 UT1 通过 ΔT 转换。时间层采用 UTC≈UT1，未包含闰秒和地球定向参数（EOP）。
远古和远期的 ΔT 不确定性会影响民用时刻，接近午夜的天象还可能因此改变归日。
历史模式采用历表归日，查询时可分别读取天象时刻与历书标注日。

## 定朔设置

`solveNewMoon()` 的 `moonLatitudeTerms` 控制日期框架变换使用的黄纬项数，
可取 `0`、`5`、`10`、`20` 或 `'full'`，默认 `10`。
增加项数可减小黄纬截断对结果的影响；`'full'` 使用全部 277 项。
完整月球位置与状态接口始终使用全部纬度项。

默认求解器用低项数模型估计根，再以完整模型校正；越界或不收敛时回退到
带区间保护的 Newton 方法。`solver: 'safeguarded'` 可直接选择该方法。

## 地平观测

地平观测计算观测者视差，并支持折射、天体边缘和地平高度设置。
实时大气条件、地形、地平俯角、极移和周日光行差未纳入通用观测模型。
日出日落在高纬及接近相切时对折射和地平高度尤其敏感。

## 事件搜索

通用搜索通过离散扫描定位变号区间，再细化求根。
`stepDays` 应足够小，以分辨目标事件；同一扫描间隔内的多个根及相切根可能漏检。
较长区间宜分段搜索，并根据天体运动速度选择步长。

事件定义、坐标参考面和搜索参数见[天象搜索](./sky-events.md)。
模型来源见[第三方声明](../THIRD_PARTY_NOTICES.md)。
